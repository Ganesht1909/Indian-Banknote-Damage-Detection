# Data Sources

## Damaged / Spoilt Banknotes
Mendeley Data — Dataset of Spoilt Banknotes of India (Rupees), Version 4  
DOI: 10.17632/jh6979fg2t.4  
https://data.mendeley.com/datasets/jh6979fg2t/4

The release contains 5,125 images across eight old/new denomination classes for ₹10, ₹20, ₹50 and ₹100 damaged notes.

## Clean / Denomination Recognition
Mendeley Data — Indian Currency Dataset  
DOI: 10.17632/8ckhkssyn3.1  
https://data.mendeley.com/datasets/8ckhkssyn3/1

The release contains 1,786 images across seven Indian denominations.
